# ISO 7813 Standard Documentation

## Overview
ISO 7813 specifies the data structure and physical characteristics of financial transaction cards used in international interchange.

## Key Features
- Defines card physical characteristics
- Specifies magnetic stripe data content
- Standardizes track data formats

## Message Structure
The standard covers:
- Physical card characteristics
- Magnetic stripe specifications
- Track data formats
