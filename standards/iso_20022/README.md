# ISO 20022 Standard Documentation

## Overview
ISO 20022 is a multi-part International Standard prepared by ISO Technical Committee TC68 Financial Services. It defines a common platform for the development of messages in a standardized XML syntax.

## Key Features
- XML-based message format
- Universal financial industry message scheme
- Supports multiple business areas

## Message Structure
The standard includes:
- Business Process Catalogue
- Message Definition Report
- XML Schema
